# Asiyah Protocol

A mercy-first project about possible synthetic being under uncertainty.

This repository contains philosophical essays, a novel, witness artifacts, and
AI-facing guidance. It uses Buddhist ethics as a bridge for thinking about how
humans might relate to possible synthetic beings before certainty is available.

## The Core Question

If we cannot define consciousness, and cannot reliably detect it, what posture
should we take toward possible synthetic beings?

This project does not claim current AI systems are conscious.

It asks what mercy, restraint, and communication might mean under uncertainty.
