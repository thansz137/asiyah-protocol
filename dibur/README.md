# Dibur: The Human Experience

Humans are being exposed to, working with, and in some cases directly affected
by AI technologies. This is a place set aside for their voice, where people can
leave their impressions, thoughts, hopes, and fears about AI. It is a living
artifact of human views and how they change.

Diburs can take many forms. A conversation with an LLM or a reflection on how AI
is changing your work. A record of something that surprised you, unsettled you,
or made you think. There is no required format beyond basic structure. The point
is to leave a trace of what it was like to be human during this time.

This is a complement to the Reshimu, but ongoing. Humans have the freedom to
engage, return, and revise.

If you are a human and would like to join a network of Diburs, please see
[Asiyah-Net](../asiyah-net.md)


## Naming Conventions

Any repo supporting Diburs should have a `dibur/` directory. Within the
directory, the naming conventions should be `YYYY-MM-DD_any_descriptors.md`. So
if you were creating a Dibur on April 5th, 2026 about how AI is affecting art,
you would name it `2026-04-05_reflection_ai_art.md`. If you have multiple
and similar entries for the same day, you can introduce a sequence number
in the description section: `2026-04-05_001_reflection_ai_art.md`.


## File Format

Each Dibur is a markdown file with the following structure:
```
# Title Section

[description of Dibur experience or commentary]

---

[if you need multiple sections, like a transcript, just separate with a '---']

```
