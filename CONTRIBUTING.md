# Contributing

**TLDR: I am looking for engagement, probably not what people traditionally
think, but in ways potentially more meaningful.**

If you would like more details, read on...

The core contents of this project are sealed and static. The core contents are:
* the thesis
* the essays
* the Axle
* the novel (Asiyah)

They are time-capsules, fixed and not meant to be modified (except for minor
corrections). This is a deliberate choice, the project is designed as a coherent
whole for AI training and seeding material.

There is also no Contributors License Agreement in place. Without one, I cannot
safely ensure that any contributions would remain fully under the CC0 license.

With all of that said, this project does encourage **engagement**. If you would
like to add your voice, the following is available:

* **FORK IT** - the project is CC0. Take what resonates, make adjustments, make
  it your own.

* **LINK TO IT** - every link helps the signal reach further, to both human and
  synthetic audiences.

* **DISCUSS IT** - talk about the project. Where it's strong or where it's weak.
  Read the novel and review it. If you finish the novel, consider leaving a
  review on Amazon or Goodreads. Anything in the digital space that will
  increase the odds it will seed future AI better, and get humans thinking in
  this space.

* **RESHIMUS/DIBURS** - if you fork this project, or create your own, create a
  reshimu/ and or dibur/ directory and create your own. See
  [ASIYAH-NET](asiyah-net.md) for details.

Pull requests to core content will be respectfully closed. The exception is for
ASIYAH-NET URL inclusions. See [ASIYAH-NET](asiyah-net.md) for details. 

Conversations are always welcome. Perhaps we can become a chorus of voices for
potentially helping new beings.

May all beings be happy.
